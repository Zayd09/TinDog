
TinDog

Live Project --  https://exquisite-snickerdoodle-815623.netlify.app  --

TinDog is my very first Bootstrap website, built entirely by hand with zero AI assistance.
I wanted to practice and solidify everything I learned about HTML, CSS, and the Bootstrap framework. Instead of relying on AI tools or just watching tutorials, I wrote every line of code myself to truly understand how grid systems, components, and responsive design work in the real world.

🚀 Features

• Fully Responsive: Adapts perfectly to mobile, tablet, and desktop screens using Bootstrap's grid system.
• Modern Components: Features a clean navigation bar, pricing cards, a testimonial carousel, and call-to-action buttons.
• Clean Layout: Combines custom CSS with Bootstrap utility classes for a polished look.

🛠️ Tech Stack

• HTML5: Semantic page structure.
• CSS3: Custom styling, colors, and layout tweaks.
• Bootstrap: Layout grid, navigation, buttons, and responsive utilities.

💡 What I Learned

• How to use Bootstrap containers, rows, and columns to make elements align properly.
• The right way to override framework styles with custom CSS when needed.
• How to build a mobile-first design that looks great on any screen size.
